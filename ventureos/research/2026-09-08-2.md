## P014. 웹소설/웹툰 작가가 여러 연재 플랫폼의 정산을 한눈에 파악하지 못한다

- **타깃 고객**: 카카오페이지, 네이버시리즈, 문피아, 노벨피아, 리디 등 2개 이상 플랫폼에 동시 연재/유통하는 웹소설·웹툰 작가 (특히 중소 출판사 계약 작가)
- **문제 설명**: 웹소설 플랫폼마다 정산 주기(예: 1월 조회수가 3~4월에 정산)와 수수료 체계(작가:출판사 7:3~8:2, 플랫폼 수수료 30~50% 등)가 제각각이라, 여러 플랫폼에 동시 유통되는 작품의 실제 수익을 작가 스스로 통합해서 파악하기 어렵다. 대형 플랫폼(카카오엔터 등)은 자사 작품에 한해 자체 파트너 포털을 제공하지만, 여러 플랫폼·여러 출판사에 걸친 통합 대시보드는 존재하지 않는다.
- **현재 해결 방법**: 플랫폼별로 개별 로그인해서 확인, 영세 출판사는 엑셀로 정산 내역을 받아 수기 대조, 커뮤니티(디시인사이드 웹소설 갤러리 등)에서 "플랫폼별 정산 비율" 정보를 서로 공유
- **불편 포인트**:
  - 플랫폼마다 정산 시점이 2~3개월씩 밀려 들어와 "이번 달 실제 수입"을 계산하기 어려움
  - 영세 출판사는 정산 내역을 엑셀 파일로만 제공해 통합 관리가 수작업
  - 세금 신고(종합소득세) 시 여러 출처의 수입을 다시 취합해야 함
- **발생 빈도**: 매월(정산 확인), 연 1회 집중(종합소득세 신고 시 총수입 취합)
- **문제 심각도 (0~10)**: 5
- **기존 지출 (돈/시간)**: 매월 여러 플랫폼을 돌며 확인하는 시간, 수기 대조 오류로 인한 재확인 시간
- **가능한 AI 해결 방향**: 작가가 각 플랫폼 정산 화면 캡처/엑셀 업로드 또는 이메일 정산서를 연동하면 자동으로 파싱해 통합 대시보드에 월별/작품별/플랫폼별 수익을 보여주고, 종합소득세 신고용 연간 합산 리포트를 자동 생성하는 웹 서비스
- **예상 수익 모델**: 작가 대상 월 구독(무료 플랜은 플랫폼 2개까지, 유료는 무제한), 세무사/장부대행 서비스 제휴 수수료
- **MVP 예상 비용 (원)**: 4,000,000 ~ 7,000,000 (플랫폼별 정산서 포맷이 상이해 파싱 로직 개발에 시간 소요 예상)
- **조사 신뢰도 (0~5)**: 3

## P015. 소규모 매장(1~2개) 사장님이 배민·쿠팡이츠·요기요 정산을 앱마다 따로 확인해야 한다

- **타깃 고객**: 배달앱 3개 이상에 입점한 개인 자영업자(치킨집, 분식집 등 1~2개 매장 규모, 프랜차이즈 본사가 아닌 개인 사장님)
- **문제 설명**: 배달의민족은 주 단위, 쿠팡이츠는 일 단위, 요기요·땡겨요는 또 다른 주기로 정산되며 수수료 체계도 앱마다 다르다. 여러 배달앱을 동시 운영하는 사장님은 매출·정산을 앱마다 따로 로그인해서 확인해야 해서 월 상당한 시간이 소요된다는 업계 자료가 있다. 기존 통합 솔루션(매장천사, 프랜차이즈 본사용 벤터 등)은 대부분 다점포 프랜차이즈 본사를 겨냥해 가격/기능이 무거워, 1~2개 매장을 운영하는 개인 사장님에게는 접근성이 낮다.
- **현재 해결 방법**: 배달앱마다 사장님 앱을 개별 설치해서 확인, 엑셀에 수기로 매출 옮겨적기, POS기 연동 프로그램 별도 구독
- **불편 포인트**:
  - 앱마다 다른 정산 주기·수수료 체계를 매번 따로 확인
  - 프로모션/광고비 반영 여부가 앱마다 달라 "실수령액"을 계산하기 어려움
  - 기존 통합 관리 솔루션은 다점포 프랜차이즈 본사 대상이라 1인 사장님에게는 과한 기능+비용
- **발생 빈도**: 주 단위(정산 확인), 월 단위(전체 매출 정리)
- **문제 심각도 (0~10)**: 6
- **기존 지출 (돈/시간)**: "월 40시간 이상" 소요된다는 업계 추정치, POS 프로그램 구독료(기존)
- **가능한 AI 해결 방향**: 배달앱별 사장님센터 로그인 정보를 연동(또는 정산 내역 캡처/엑셀 업로드)하면 앱별 매출·수수료·프로모션 반영 실수령액을 한 화면에 통합해서 보여주는 1인 사장님 전용 라이트 대시보드
- **예상 수익 모델**: 매장당 저가 월 구독(프랜차이즈용 솔루션보다 훨씬 저렴하게 포지셔닝), 세무 신고 연계 제휴 수수료
- **MVP 예상 비용 (원)**: 5,000,000 ~ 8,000,000 (배달앱 3~4개 데이터 연동/파싱 필요)
- **조사 신뢰도 (0~5)**: 3

## P016. 프리랜서 통역사·번역사가 여러 클라이언트의 견적서·프로젝트 진행 상태를 따로 관리해야 한다

- **타깃 고객**: 여러 에이전시·클라이언트와 동시에 일하는 프리랜서 통역사/번역사(특히 초보~중급, 번역 회사 소속이 아닌 독립 프리랜서)
- **문제 설명**: 번역가들이 실무에서 겪는 어려움을 다룬 자료들에 따르면 초보 프리랜서 번역가들은 견적 산정, 프로젝트별 진행 상태 관리에서 흔히 실수를 저지른다. 시장에 존재하는 도구(MemoQ, XTM 등)는 번역 메모리·CAT 툴 중심이라 견적서 발행이나 여러 클라이언트에 걸친 프로젝트 진행 상태·입금 여부 관리 기능은 약하다.
- **현재 해결 방법**: 엑셀/구글시트로 클라이언트별 프로젝트 목록 수기 관리, 견적서는 한글/워드 템플릿으로 매번 새로 작성, 입금 여부는 통장 내역과 수동 대조
- **불편 포인트**:
  - 클라이언트마다 다른 단가(글자수 기준/시간 기준/분량 기준)를 매번 다시 계산
  - 여러 건이 동시에 진행될 때 "이 건은 견적만 보냈나, 계약까지 됐나, 입금은 됐나"를 헷갈림
  - CAT 툴은 번역 작업 자체엔 도움이 되지만 비즈니스(견적/청구/정산) 관리 기능은 없음
- **발생 빈도**: 신규 프로젝트 문의가 올 때마다(주 수 건), 월말 정산 시
- **문제 심각도 (0~10)**: 4
- **기존 지출 (돈/시간)**: 견적서 작성/프로젝트 상태 확인에 건당 수십 분, CAT 툴 라이선스 비용(별도)
- **가능한 AI 해결 방향**: 클라이언트·프로젝트별 단가 설정을 저장해두면 분량/시간만 입력해도 견적서를 자동 생성하고, 프로젝트 상태(견적→계약→작업중→납품→입금)를 칸반 형태로 관리하는 프리랜서 통역·번역가 전용 경량 CRM
- **예상 수익 모델**: 프리랜서 대상 저가 월 구독(무료 플랜 3건까지, 유료 무제한)
- **MVP 예상 비용 (원)**: 3,000,000 ~ 5,000,000 (범용 프리랜서 CRM 대비 견적 계산 로직만 특화하면 상대적으로 단순)
- **조사 신뢰도 (0~5)**: 2 (직접적인 "귀찮다"는 커뮤니티 원문은 확보하지 못하고 실수 사례/도구 기능 비교로 간접 추정)

- **문제 설명**: SNS 팔로워를 통해 직접 의뢰가 들어오는 구조상, 의뢰 접수-입금 확인-작업 순서(대기열)-진행상황 공유-납품을 개인이 직접 관리해야 한다. 해외에는 VGen 같은 커미션 관리 플랫폼이 존재하지만 한국어/원화 결제에 최적화되어 있지 않고, 한국 커뮤니티(루리웹 등)에서도 "커미션 관리 프로그램"을 개인이 직접 만들어 홍보하는 게시글이 있을 정도로 자체적인 도구 수요가 확인된다.
- **현재 해결 방법**: 엑셀/구글폼으로 의뢰 접수 양식 제작, 트위터 고정 트윗으로 대기열 순번 공지, 개인이 만든 비공식 관리 프로그램 사용
- **불편 포인트**:
  - 의뢰 접수, 입금 확인, 작업 순서 안내를 각각 다른 채널(DM, 구글폼, 트위터)로 따로 처리
  - 계약 불이행(마감 지연, 노쇼 의뢰인)으로 인한 분쟁이 커뮤니티에서 반복 언급됨
  - 대기열이 길어질수록 어느 의뢰가 몇 번째인지 작가 본인도 헷갈림
- **발생 빈도**: 의뢰가 들어올 때마다(활동 규모에 따라 주 수 건~수십 건)
- **문제 심각도 (0~10)**: 3
- **기존 지출 (돈/시간)**: 관리에 드는 시간, 일부는 이미 구글폼/엑셀 등 무료 도구 사용 중이라 직접 지출은 적음
- **가능한 AI 해결 방향**: 의뢰 접수 폼 생성, 대기열 자동 관리(순번/예상 완료일 자동 안내), 입금 확인 체크리스트, 진행상황 공유 링크(의뢰인이 볼 수 있는 페이지)를 제공하는 한국어/원화 결제 특화 커미션 관리 웹 서비스
- **예상 수익 모델**: 무료 기본 제공(대기열 5건까지) + 유료 무제한/커스텀 브랜딩, 결제 연동 수수료
- **MVP 예상 비용 (원)**: 3,000,000 ~ 5,000,000
- **조사 신뢰도 (0~5)**: 2 (VGen이라는 해외 경쟁 서비스가 이미 존재해 완전한 블루오션은 아니며, 한국 시장 원문 불만은 제한적으로만 확인)

### 근거 (실제 조사로 확보)
- [커미션 작가분들을 위한 커미션 관리 프로그램 홍보합니당 - 루리웹](https://bbs.ruliweb.com/userboard/board/700051/read/9702) — 국내 일러스트레이터가 자체적으로 커미션 관리 프로그램을 만들어 공유할 만큼 기존 도구의 공백이 있었음을 방증

### 가정 (근거 없이 추측한 부분)
- VGen이 한국 사용자에게 얼마나 알려져 있고 실제로 쓰이는지, 언어/결제 장벽으로 인해 한국 작가들이 이용을 꺼리는지는 직접 확인하지 못함
- 시장 규모(SNS 커미션으로 활동하는 한국 일러스트레이터 수)는 추정 근거 없음

## P021. 개인 방문요양보호사가 여러 어르신 방문 스케줄과 이동 동선을 스스로 관리해야 한다

- **타깃 고객**: 장기요양기관에 소속되어 여러 수급자(어르신) 가정을 방문하는 요양보호사, 특히 등록 형태로 여러 건을 동시에 담당하는 경우
- **문제 설명**: 방문요양은 이용자 자택을 이동하며 서비스를 제공하는 구조상 단순 근무시간만으로 관리가 안 되고, 방문지 간 이동 거리·교통 상황에 따라 실제 소요시간이 달라진다. 기존 소프트웨어(케어포, 카이포케 등)는 대부분 요양기관(사업소) 관리자가 전체 인력을 배정하기 위한 시스템이며, 요양보호사 개인이 자신의 하루 방문 순서·이동 동선을 최적화하거나 스스로 파악하기 위한 도구는 확인되지 않았다.
- **현재 해결 방법**: 기관에서 배정해준 일정을 종이/문자로 전달받아 수기 확인, 개인 지도 앱으로 각자 이동경로 별도 검색
- **불편 포인트**:
  - 모닝케어·이브닝케어 등 시간이 몰리는 구간에 여러 수급자 일정이 겹칠 위험
  - 다른 요양서비스(방문간호 등)와 시간이 겹치지 않는지 본인이 직접 체크해야 하는 경우 발생
  - 이동시간을 고려하지 않은 일정 배정으로 실질 근무시간이 늘어남
- **발생 빈도**: 매일(일과 시작 전 일정 확인), 매주(스케줄 변경 시)
- **문제 심각도 (0~10)**: 5
- **기존 지출 (돈/시간)**: 이동에 드는 시간(무급인 경우 실질 소득 감소), 일정 확인에 드는 시간
- **가능한 AI 해결 방향**: 기관이 배정한 방문 일정을 입력(또는 문자 캡처 인식)하면 이동 동선을 고려해 하루 일정을 시각화하고, 이동시간 부족·겹침 위험을 사전에 알려주는 요양보호사 개인용 일정 도우미 앱
- **예상 수익 모델**: 개인 무료 제공 + 기관 대상 B2B 제휴(요양보호사 만족도 개선 도구로 어필), 광고 없는 프리미엄 구독
- **MVP 예상 비용 (원)**: 4,000,000 ~ 6,000,000 (지도/경로 API 연동 필요)
- **조사 신뢰도 (0~5)**: 2 (기관 관리자 관점 자료는 확보했으나 요양보호사 개인 당사자의 직접 인용 후기는 제한적)

## P022. 처음 직원을 채용하는 초보 사장님이 근로계약서·4대보험 신고 절차를 어디서부터 해야 할지 막막해한다

- **타깃 고객**: 카페, 소규모 매장 등을 운영하며 생애 처음으로 직원(알바 포함)을 채용하는 1인 자영업자
- **문제 설명**: 직원을 고용하면 근로계약서 작성, 4대보험 취득신고(국민연금·건강보험·고용보험·산재보험), 급여 원천징수까지 순서대로 처리해야 하는데, 절차를 지키지 않으면 근로계약서 미작성 시 최대 500만원 과태료, 4대보험 미가입 시에도 불이익이 발생한다. 관련 가이드/계산기는 많지만 "내 상황에서 지금 뭘 해야 하는지" 순서를 안내하는 통합 체크리스트형 서비스는 확인되지 않았다.
- **현재 해결 방법**: 4대사회보험 정보연계센터(EDI) 직접 회원가입 후 신고, 노무사에게 위탁(비용 부담), 블로그/유튜브 가이드를 보며 셀프 처리
- **불편 포인트**:
  - "근로계약서 → 4대보험 신고 → 급여/원천징수" 순서 자체를 모르는 경우가 많음
  - 각 보험공단(국민연금/건강보험/근로복지공단) 사이트가 따로 있어 여러 번 반복 입력
  - 실수 시 과태료(최대 500만원) 등 금전적 리스크가 있음
- **발생 빈도**: 신규 직원 채용 시마다(사업 초기엔 반복 발생 가능)
- **문제 심각도 (0~10)**: 5
- **기존 지출 (돈/시간)**: 노무사 위탁 비용(월 수만~수십만원), 셀프 처리 시 소요 시간과 실수 리스크
- **가능한 AI 해결 방향**: 사업 형태·직원 근무조건(주휴시간, 급여 등)을 입력하면 근로계약서 초안 자동 생성, 4대보험 가입 대상 여부 자동 판정, 신고 순서를 단계별 체크리스트로 안내하는 초보 사장님 전용 웹 서비스(EDI 직접 신고 연동까지는 어렵더라도 "무엇을, 어떤 순서로, 어디서" 안내만으로도 가치 제공 가능)
- **예상 수익 모델**: 무료 체크리스트 제공 + 근로계약서 생성/저장 유료화, 노무사 상담 연계 수수료
- **MVP 예상 비용 (원)**: 3,000,000 ~ 5,000,000
- **조사 신뢰도 (0~5)**: 2 (제도 설명 자료는 풍부하나 "막막하다"는 초보 사장님의 직접 인용 후기 원문은 확보하지 못함)

## P023. 여러 개호 사업소에 등록해 掛け持ち(겸업)하는 일본 등록 헬퍼가 자신의 전체 방문 스케줄을 통합 관리하기 어렵다 (일본)

- **타깃 고객**: 일본에서 하나의 사업소에 정규 고용되지 않고, 여러 訪問介護(방문개호) 사업소에 등록 헬퍼(登録ヘルパー) 형태로 동시 소속되어 일하는 개인
- **문제 설명**: 등록 헬퍼는 여러 사업소에서 원하는 시간대로 일을 받을 수 있다는 장점이 있지만, 掛け持ち(겸업) 시 사업소 간 스케줄이 겹치지 않도록 본인이 직접 관리해야 하는 부담이 있다고 여러 업계 자료에서 공통적으로 지적된다. 기존 소프트웨어(카이포케, 프로키아스 등)는 사업소가 자신의 소속 헬퍼를 배정하기 위한 도구라 여러 사업소에 걸친 개인의 전체 일정을 통합해서 보여주는 서비스는 확인되지 않았다.
- **현재 해결 방법**: 사업소별로 전달받은 근무표를 개인 캘린더에 수기로 옮겨 적기, 종이/문자로 스케줄 통보받고 본인이 취합
- **불편 포인트**:

  - 사업소마다 근무표 전달 방식이 달라(종이, 문자, 각자 시스템) 통합 확인이 번거로움
