## P117. AI 음성 복제(딥보이스) 가족 사칭 보이스피싱을 통화 중 실시간으로 판별할 도구가 없다 (한국)

- **타깃 고객**: 자녀·부모 등 가족 명의로 걸려오는 긴급 송금 요청 전화를 받는 일반 성인(특히 중장년층 부모, 자녀를 둔 가정)
- **문제 설명**: 2026년 들어 SNS 영상·유튜브 라이브·통화 녹음에서 30초~1분 분량만 확보해도 목소리·억양·감정까지 복제하는 AI 보이스피싱이 확산되고 있다. "아이가 휴대폰을 깨뜨려 수리비를 급히 보내야 한다"는 식으로 실제 자녀 목소리와 구별이 사실상 불가능한 수준까지 발전했다.
- **현재 해결 방법**: 전화를 끊고 저장된 번호로 재발신하거나, 통신사 AI콜(스마트피싱보호·피싱아이즈·A.콜·후후 등) 앱이 악성 앱 설치·의심 발신번호를 탐지하는 정도에 그친다. 정부는 추석 연휴 24시간 특별 감시체계를 가동했지만 이는 사후 신고 대응이다.
- **불편 포인트**:
  - 진짜 목소리와 AI 복제 음성이 통화 중에는 구별되지 않아 판단을 순전히 개인 직관에 의존해야 한다
  - 기존 스팸/피싱 차단 앱은 "발신번호·악성앱 설치"만 탐지할 뿐, 통화 내용 자체(긴급 송금 요구, 문맥상 어색함)를 실시간 분석하지 않는다
  - 가족 간 사전에 정해둔 "안전 문구(코드워드)"를 통화 중 자동으로 검증해주는 서비스가 없어, 당황한 상태에서 확인 절차를 잊기 쉽다
- **발생 빈도**: 명절·연휴 등 특정 시기에 집중 급증(정부가 추석 특별감시체계 가동), 평시에도 지속 보고
- **문제 심각도 (0~10)**: 8 (실제 금전 피해 직결, 피해 판별이 기술적으로 사실상 불가능해짐)
- **기존 지출 (돈/시간)**: 피해 발생 시 1회 손실액 수십만~수천만 원, 예방 목적의 유료 안심 서비스(피싱아이즈 가족보호 등) 이용료 존재
- **가능한 AI 해결 방향**: 통화 중 실시간 STT(음성인식)로 "송금·계좌·긴급" 등 위험 키워드와 감정적 압박 패턴을 탐지해 경고 배너를 띄우고, 가족 간 사전 설정한 코드워드를 통화 앱이 자동으로 되묻는 확인 흐름을 제공. 경쟁사 스크리닝 결과 Whoscall·피싱아이즈·통신사 AI콜은 발신번호·악성앱 탐지 중심이며 "통화 내용 실시간 분석 + 코드워드 자동검증" 조합 서비스는 확인되지 않아 차별화 여지가 있음
- **예상 수익 모델**: 개인/가족 단위 월 구독(프리미엄 가족보호팩), 통신사·카드사 화이트라벨 제휴
- **MVP 예상 비용 (원)**: 약 3000만~6000만 (STT API 연동 + 키워드/패턴 탐지 로직 + 안드로이드 통화 오버레이 앱)
- **조사 신뢰도 (0~5)**: 4

## P118. 결혼 성수기 모바일 청첩장·부고 문자가 지인 번호로 스푸핑되어 소비자가 진위를 스스로 판별할 수 없다 (한국)

- **타깃 고객**: 가을 결혼 성수기(9~11월)에 지인의 청첩장·부고 문자를 자주 받는 20~50대 일반인
- **문제 설명**: "결혼", "청첩장", "부고" 키워드를 활용한 스미싱이 급증하고 있으며, 공격자는 발신번호를 수신자 스마트폰에 저장된 지인 번호로 표기해 실제 지인이 보낸 문자로 오인하도록 유도한다("숨니봇" 트로이목마 등). 클릭 시 은행 인증서·연락처·사진이 탈취된다.
- **현재 해결 방법**: Whoscall 웹체커, NICE 'URL 해킹안심' 등으로 링크를 수동 복사해 검사하거나, KISA 118로 신고하는 정도. 클릭 전 사전 예방 수단이 약함.
- **불편 포인트**:
  - 발신번호가 저장된 지인 번호로 위장(스푸핑)되면 기존 스팸 차단 앱(미확인 번호 식별 중심)이 걸러내지 못한다
  - 결혼식·장례식이라는 감정적으로 급박한 맥락 때문에 사용자가 침착하게 링크를 검증할 여유가 없다
  - URL 검사 도구가 있어도 "복사해서 별도 앱에 붙여넣기"라는 번거로운 절차 때문에 실사용률이 낮다
- **발생 빈도**: 결혼 성수기(봄·가을)와 명절 등 특정 시즌에 집중 급증
- **문제 심각도 (0~10)**: 7 (금융정보·연락처 탈취로 2차 피해 확산)
- **기존 지출 (돈/시간)**: 올해 상반기 스미싱 피해 88만 건 보고, 피해 시 개인 금전 손실 발생
- **가능한 AI 해결 방향**: 문자 수신 즉시 온디바이스에서 URL을 자동 스캔하고, "저장된 연락처 번호 + 결혼/부고 키워드 + 외부 링크" 조합을 고위험 패턴으로 자동 플래그하는 SMS 필터 앱. 경쟁사 스크리닝 결과 Whoscall 웹체커·NICE URL해킹안심은 이미 존재하지만 "지인 번호 스푸핑 자동 탐지"에 특화된 서비스는 확인되지 않아, 기존 URL 검사 도구와 차별화된 좁은 틈새로 접근 가능
- **예상 수익 모델**: freemium(기본 스캔 무료, 가족 다인 보호팩 유료 구독), 통신사 부가서비스 제휴
- **MVP 예상 비용 (원)**: 약 2000만~4000만 (SMS 수신 접근권 앱 + KISA/VirusTotal API 연동 URL 스캔)
- **조사 신뢰도 (0~5)**: 4

## P119. 가을 중고차 성수기, 보험처리 안 된 침수차는 카히스토리로도 확인이 안 돼 소비자가 스스로 검증할 방법이 없다 (한국)

- **타깃 고객**: 9~11월 가을 성수기에 중고차(특히 개인 간 직거래·소규모 매매상사)를 구매하려는 일반 소비자
- **문제 설명**: 자차보험 미가입 또는 보험 처리를 거치지 않고 사설로 수리한 침수차는 카히스토리에 이력이 전혀 남지 않는다. 국토교통부 시스템과 카히스토리 간 실시간 연계도 미흡해 사고 발생부터 전산 등록까지 수개월 공백이 생긴다. 여름 폭우 후 가을은 이런 "세탁된" 침수차가 시장에 대거 유입되는 시기다.
- **현재 해결 방법**: 카히스토리 무료 조회(보험처리 건만 커버), 엔카닷컴의 '엔카믿고' 90일 침수차 책임환불 프로그램(엔카 플랫폼 매물에만 적용), 정부는 2026년 8월 '중고차 소비자 보호대책'으로 침수 은폐 시 영업정지 처분 예고
- **불편 포인트**:
  - 카히스토리 조회 결과가 "이상 없음"이어도 실제로는 사설 수리된 침수차일 수 있어 소비자가 안심할 수 없다
  - 개인 간 직거래·중고나라·당근마켓 등에서는 엔카 같은 플랫폼 보증 프로그램 자체가 적용되지 않는다
  - 침수 흔적(부식, 곰팡이 냄새, 전장 부품 오작동)을 비전문가가 육안으로 판별하기 매우 어렵다
- **발생 빈도**: 매년 7~10월 장마·태풍 이후 시즌성으로 반복, 손해보험협회 추산 연간 약 2만 대 이상 유통 가능성
- **문제 심각도 (0~10)**: 8 (구매액 수천만 원 손실 + 안전 문제 직결)
- **기존 지출 (돈/시간)**: 중고차 1대당 수백만~수천만 원, 사설 정밀점검 비용 추가 부담
- **가능한 AI 해결 방향**: 사용자가 차량 실내외(카펫 아래, 안전벨트 봉제선, 퓨즈박스, 시트 레일 등) 다각도 사진을 업로드하면 AI가 침수 흔적(부식·변색·오염 패턴)을 1차 스크리닝하고, 차대번호(VIN) 기반으로 카히스토리·보험개발원 공개 데이터를 자동 통합 조회해주는 개인용 점검 체크리스트 앱. 경쟁사 스크리닝 결과 카히스토리(무료·보험이력만)와 엔카 환불보증(자사 플랫폼 매물 한정)은 존재하지만, "개인 간 직거래용 AI 사진판독+통합조회" 서비스는 확인되지 않아 사각지대를 공략 가능
- **예상 수익 모델**: 건당 유료 리포트(1만~3만 원), 정밀점검 업체 제휴 수수료
- **MVP 예상 비용 (원)**: 약 4000만~8000만 (이미지 분류 모델 학습/파인튜닝 + VIN 조회 API 연동)
- **조사 신뢰도 (0~5)**: 4

## P126. 2026년 실업급여 반복수급 규정 강화로 내가 감액 대상인지, 몇 회차인지 스스로 정확히 파악하기 어렵다 (한국)

- **타깃 고객**: 계약직·단기직을 반복하며 실업급여를 여러 차례 받은 이력이 있는 근로자
- **문제 설명**: 2026년부터 최근 5년 내 3회 이상 실업급여 수급 시 '반복수급자'로 분류돼 대기기간이 최장 4주까지 늘어나고, 지급액이 최대 50%까지 감액될 수 있다. 실업인정 주기도 4주에서 2주 단위로 단축되고 대면 출석이 늘어난다. 그러나 "내가 몇 회차 수급자인지", "이번에 얼마나 감액되는지"를 스스로 정확히 계산하기 어렵다.
- **현재 해결 방법**: 고용노동부 work24 사이트의 실업급여 모의계산, 노동OK·사람인·잡코리아 등 민간 계산기 다수 존재. 하지만 검색 결과 "반복수급 감액을 자동으로 반영해 계산하는" 기능이 명확히 확인되는 곳은 드물다.
- **불편 포인트**:
  - 기존 계산기 대부분은 "이번이 처음 수급"이라는 전제로 단순 계산하며, 과거 수급 이력을 입력해 반복수급 감액을 자동 반영하는 기능이 부족하다

- **문제 심각도 (0~10)**: 5 (수급액 최대 50% 감액은 생계에 직접 영향이나, 대상자군이 제한적)

- **예상 수익 모델**: 무료 기본 계산 + 노무사 상담 연계 수수료
