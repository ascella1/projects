# 07. UI 와이어프레임 (텍스트 기반)

실제 비주얼 디자인 이전 단계의 레이아웃/정보구조 정의. 톤앤매너는 [01-product-specification.md](01-product-specification.md) §5 참조.

## 1. 온보딩

```
┌─────────────────────────────┐
│  ●○○○                       │  ← 진행 인디케이터
│                              │
│   당신에 대해 알려주세요        │
│   (몇 가지만 입력하면 바로       │
│    맞춤 혜택을 볼 수 있어요)     │
│                              │
│   나이대       [26]           │
│   거주지       [서울 ▾][강남구▾]│
│                              │
│              [다음 →]         │
│           [나중에 할게요]       │
└─────────────────────────────┘
```
4단계: 나이/성별 → 지역 → 고용상태 → (선택) 소득·결혼·자녀·주택·병역·장애. 언제든 스킵 가능, 홈에서 계속 채우도록 유도.

## 2. 홈 대시보드

```
┌─────────────────────────────┐
│ 안녕하세요, 민준님 👋          │
│                              │
│ ┌──────────┐ ┌──────────┐   │
│ │예상 월혜택 │ │예상 연혜택 │   │
│ │ 20만원    │ │ 240만원   │   │
│ └──────────┘ └──────────┘   │
│                              │
│ 🔥 마감임박                   │
│ [카드][카드][카드]  →스크롤     │
│                              │
│ ✨ 당신을 위한 추천             │
│ [카드][카드][카드]             │
│                              │
│ 🆕 신규 혜택                  │
│ [카드][카드][카드]             │
│                              │
│ 🕓 최근 추가                  │
│ [카드][카드][카드]             │
├─────────────────────────────┤
│ [홈] [검색] [AI] [알림] [내정보]│  ← 하단 탭
└─────────────────────────────┘
```
카드 구성: 아이콘 · 제목 · 예상금액 · 자격배지(초록/노랑) · D-day.

## 3. 검색

```
┌─────────────────────────────┐
│ 🔍 "26살 신혼부부 전세"  [입력]  │
│                              │
│ 필터: [카테고리▾][지역▾][정렬▾] │
│                              │
│ 검색결과 24건                 │
│ ─────────────────────────── │
│ [혜택카드]                    │
│ [혜택카드]                    │
│ [혜택카드]                    │
└─────────────────────────────┘
```
자연어 입력 그대로 검색창에 받고, 서버가 키워드+속성 추출해 필터를 자동 적용 제안 (예: "26살" → 나이필터 자동 세팅 제안 칩).

## 4. 혜택 상세

```
┌─────────────────────────────┐
│ ← 청년월세 특별지원            │
│                              │
│ [ELIGIBLE ✓ 받을 수 있어요]   │
│                              │
│ 💰 월 20만원 (최대 12개월)     │
│ 📅 마감 D-12 (2026-08-02)     │
│                              │
│ ▾ 왜 받을 수 있나요?           │
│   ✓ 나이 만 26세 (19~34 조건) │
│   ✓ 연소득 3,200만원 (조건이하) │
│   ✓ 무주택 (조건충족)          │
│                              │
│ ▾ 신청 방법 / 필요서류         │
│ ▾ FAQ                        │
│ ▾ AI 요약                     │
│                              │
│ [공식 사이트로 신청하기 →]      │
│ [🔖 저장] [↗ 공유] [⚖ 비교담기] │
└─────────────────────────────┘
```

## 5. AI 챗

```
┌─────────────────────────────┐
│ ← AI에게 물어보기              │
│                              │
│  🤖 어떤 상황이신가요?          │
│                              │
│              나 퇴사하려고요 👤 │
│                              │
│  🤖 퇴사 후 받을 수 있는       │
│     혜택을 확인했어요:          │
│     ┌───────────────┐        │
│     │ 실업급여 · ELIGIBLE│      │
│     │ 국민내일배움카드   │        │
│     └───────────────┘        │
│     [자세히 보기]              │
│                              │
│ [메시지 입력...]        [전송] │
└─────────────────────────────┘
```
AI 응답 내 혜택 언급은 항상 카드 형태로 렌더링(자유 텍스트로 금액/자격을 쓰지 않음, [06 참고](06-ai-integration-design.md) §7).
