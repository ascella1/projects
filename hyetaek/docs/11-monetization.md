# 11. 수익화 전략

정부 혜택 정보 자체는 공공성이 강하므로, **핵심 정보(자격 판정, 혜택 조회)는 항상 무료**를 원칙으로 하고, 부가가치(편의/속도/전문성)에 과금하는 프리미엄 모델을 기본으로 한다. 정부 서비스 신뢰도를 해치는 선정적 광고는 지양한다.

## 1. Freemium 구독 모델

| 등급 | 제공 |
|---|---|
| 무료 | 전체 혜택 조회, 자격 판정, 검색, 북마크, 알림, AI 챗 월 N회 |
| 프리미엄 (구독) | AI 챗 무제한, 서류 자동작성 어시스턴트, 가족 계정, 고급 알림(정책 변경 실시간), 광고 없는 경험 |

- 구독가는 소액(₩3,900~₩7,900/월 수준)으로 대중적 접근성 유지, 연간 결제 할인.

## 2. 제휴/매칭 수수료 모델

- **전문가 매칭**: 세무사/노무사/행정사 상담 연결 시 성사 수수료.
- **금융 상품 연계**: 청년도약계좌 등 실제 가입이 필요한 금융상품에 대해 제휴 은행 신청 연결 시 CPA(성과형) 수수료 —단, 정보의 중립성을 해치지 않도록 추천 로직과 광고/제휴를 UI적으로 명확히 분리 표기.

## 3. B2B / B2G 모델

- **지자체 제휴**: 지자체가 자체 복지 캠페인/신규 정책을 우선 노출하고 싶을 때 노출 슬롯 제공 (네이티브 광고 아닌, "우리 지역 소식" 섹션 형태로 UX 일관성 유지).
- **기업 복지 연계**: 기업이 임직원 복리후생 안내용으로 화이트라벨/API 라이선스 제공 (예: 사내 인트라넷에 "우리 직원이 받을 수 있는 정부 혜택" 위젯 임베드).

## 4. 데이터/인사이트 상품 (장기)

- 익명화·집계된 "지역별/연령별 혜택 수요" 인사이트를 지자체/연구기관에 제공 (개인 식별 정보 제외, 통계적 집계만).

## 5. 하지 않을 것

- 배너/전면 광고로 정보 신뢰도를 해치는 방식은 지양.
- 자격 판정 결과를 광고주에게 유리하게 왜곡하는 방식 금지 (룰 엔진과 광고/추천 로직의 완전한 분리 유지, [05](05-eligibility-rule-engine.md) 원칙과 일관).

## 6. 단계별 수익화 로드맵

1. MVP~베타: 수익화 없음, 리텐션/신뢰 구축에 집중
2. 정식 출시 후: 프리미엄 구독 도입 (AI 챗 사용량 기반)
3. 사용자 기반 확대 후: 제휴/매칭 수수료, B2G 파일럿
4. 100만 유저 규모: B2B 화이트라벨, 데이터 인사이트 상품
