# 01. 전체 제품 기획서 (Full Product Specification)

## 1. 제품 비전

"정부 혜택 + AI + 개인화 대시보드" — 사용자가 몇 가지 정보만 입력하면, 지금 받을 수 있는 모든 정부/지자체 혜택을 순위화해서 보여주고, AI가 대화로 안내하는 모바일 앱.

## 2. 페르소나

### 페르소나 A — 사회초년생 김민준 (26세, 서울 거주, 중소기업 재직)
- 니즈: 청년도약계좌, 청년 월세지원, 전세자금대출 이자지원
- 행동: "내가 청년도약계좌 될까?" 같은 자연어 질문을 던짐

### 페르소나 B — 신혼부부 박지현 (32세, 수원 이주 예정)
- 니즈: 신혼부부 전세자금, 출산장려금, 이사/전입 관련 지자체 지원
- 행동: "이사 가요" 라고만 말해도 관련 혜택 묶음을 추천받고 싶어함

### 페르소나 C — 프리랜서 이수아 (29세, 프리랜서 디자이너)
- 니즈: 고용보험 사각지대 지원(예술인/노무제공자 고용보험), 프리랜서 대상 세제 지원
- 행동: 고용형태 특성상 일반 포털에서 필터링이 잘 안 됨 → 정확한 자격 판별이 핵심 가치

### 페르소나 D — 퇴사 예정자 정하늘 (34세, 퇴사 고민 중)
- 니즈: 퇴사 후 실업급여, 국민내일배움카드, 건강보험 임의계속가입 등 상황 변화형 혜택
- 행동: "저 퇴사하려고 해요" 같은 상황 서술형 질문

## 3. 핵심 사용자 플로우

```
[앱 최초 실행]
   → 온보딩 (3~4단계, 스킵 가능)
      - 나이/성별
      - 거주지(시/도, 시/군/구)
      - 고용상태 (직장인/자영업/프리랜서/구직중/학생 등)
      - 선택: 소득, 결혼여부, 자녀, 주택보유, 병역, 장애여부
   → 홈 대시보드 (즉시 개인화된 카드 노출)
      - 예상 월 혜택 / 예상 연 혜택 카드
      - 신규 / 마감임박 / 추천 / 최근 추가 섹션
   → 혜택 상세 페이지
      - 자격 판정 결과 + WHY 설명 + 신청 링크
   → (선택) AI 챗으로 자연어 질문
   → 프로필 변경 시 전체 재계산 (실시간)
```

## 4. 기능 전체 목록

### 4.1 홈 / 대시보드
- 예상 월간 혜택 합계 카드
- 예상 연간 혜택 합계 카드
- 신규 혜택 / 마감임박 / 추천 / 최근 추가 섹션 (가로 스크롤 카드)
- 혜택 점수(Benefit Score), 우선순위 점수(Priority Score) 배지

### 4.2 검색
- 자연어 검색 ("26살", "학생", "신혼", "창업" 등 키워드/문장 혼합 입력)
- 필터: 카테고리, 지역, 금액대, 마감일

### 4.3 혜택 상세
- 제목/설명/대상/금액/신청방법/필요서류/마감일/공식 링크/FAQ/AI 요약
- 자격 판정 배지 (Eligible / Possibly Eligible / Not Eligible) + WHY

### 4.4 AI 챗
- 자유 대화형 질문 응답 ("이 혜택 받을 수 있어?", "퇴사하면 뭐 받을 수 있어?")
- 대화 중 프로필 정보 추출 → 프로필 자동 업데이트 제안

### 4.5 알림
- 신규 혜택 등록, 연령/조건 충족 진입, 마감 D-3, 지역 신규 지원 등

### 4.6 프로필
- 나이, 지역, 소득, 직업, 결혼, 자녀, 주택, 학생, 병역 등
- 변경 시 즉시 전체 재계산

### 4.7 부가 기능
- 저축 계산기(Savings Calculator), 정부 지원 캘린더, 북마크, 공유, 혜택 비교, 자격 타임라인(나이/상태 변화에 따른 미래 자격 예측)

## 5. UI/UX 스타일 가이드

- **톤**: 모던 핀테크 (토스/뱅크샐러드 계열 감성), 신뢰감 있는 정부 서비스 톤 절충
- **컬러**: 미니멀 팔레트, 브랜드 1색 + 중립 그레이 스케일, 상태색(초록=Eligible, 노랑=Possibly, 회색=Not Eligible)
- **컴포넌트**: 라운드 카드(반경 16~20px), 큰 여백, 카드형 리스트, 부드러운 트랜지션(200~300ms)
- **다크모드**: 전 화면 지원
- **접근성**: 텍스트 대비 WCAG AA 이상, 폰트 크기 동적 조정 대응

## 6. 비기능 요구사항

- 콜드 스타트 2초 이내 (캐시된 홈 데이터 즉시 렌더)
- 오프라인에서도 마지막 캐시 데이터로 홈/상세 열람 가능
- 100만 사용자 기준 백엔드 확장성 고려 ([10-deployment-scalability.md](10-deployment-scalability.md))
- 개인정보보호법/공공데이터 이용 약관 준수
