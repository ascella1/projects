# 08. 개발 로드맵 + MVP + 프리미엄 기능

## 1. 개발 로드맵

### Phase 0 — 기획/설계 (완료, 본 문서 세트)
- 제품 스펙, DB 스키마, 아키텍처, 룰엔진/AI 설계 확정

### Phase 1 — 데이터 & 룰엔진 기반 구축 (4~6주)
- 정부 Open API 3~4종 어댑터 구현 (정부24, 공공데이터포털, 청년정책, 고용24)
- 내부 DB 스키마 구축, 수집 파이프라인 배포
- 룰 엔진 코어 구현 + 유닛테스트 (테스트 최우선 영역)
- 관리자용 룰 입력 최소 기능(스크립트/시드 데이터 수준)

### Phase 2 — MVP 앱 (6~8주)
- Flutter 앱 골격 (Clean Architecture, GoRouter, Riverpod)
- 온보딩, 홈 대시보드, 검색, 상세, 프로필, 북마크
- 내부 REST API 연동, 오프라인 캐시(Drift)
- 앱스토어/플레이스토어 비공개 베타 배포

### Phase 3 — AI 통합 (4~6주)
- AI 챗 (RAG 파이프라인 + Provider 추상화)
- 대화형 프로필 추출
- 상황 시나리오(퇴사/이사 등) 매핑 테이블 구축

### Phase 4 — 알림 & 참여 기능 (3~4주)
- 푸시 알림 (신규/마감임박/자격변경)
- 정부 지원 캘린더, 저축 계산기, 혜택 비교, 자격 타임라인
- 공개 베타 → 정식 출시

### Phase 5 — 고도화 & 스케일 (지속)
- 지자체 데이터 확장 (17개 시도 개별 API)
- 프리미엄 기능, 수익화 실험
- 100만 유저 대비 인프라 확장 ([10 참고](10-deployment-scalability.md))

## 2. MVP 기능 범위 (필수만)

| 포함 | 제외 (Phase 3 이후) |
|---|---|
| 온보딩 (핵심 필드만) | AI 챗 |
| 홈 대시보드 (월/연 예상, 추천/마감임박) | 자격 타임라인 |
| 검색 (키워드 기반, 자연어 파싱은 간단 규칙) | 혜택 비교 |
| 혜택 상세 + WHY 설명 | 저축 계산기 |
| 프로필 + 재계산 | 정부 캘린더 |
| 북마크 | 푸시 알림 |
| 룰 엔진 (핵심 3단계 판정) | 지자체 전체 데이터 (초기 2~3개 지역만) |

MVP 성공 기준: 온보딩 완료율, D1/D7 리텐션, 혜택 상세→신청 링크 클릭률.

## 3. 향후 프리미엄 기능 (수익화 연계, [11 참고](11-monetization.md))

- **AI 챗 무제한 이용권** (무료는 월 N회 제한)
- **서류 자동 작성/체크리스트 어시스턴트** — 필요서류를 사용자 정보로 미리 채워주는 PDF 폼 헬퍼
- **전문가 매칭 연계** — 세무사/노무사/행정사 상담 연결 (수수료 기반)
- **가족 계정** — 부모/자녀 프로필을 묶어 가구 단위 혜택 통합 조회
- **알림 고도화** — 정책 변경 실시간 알림, 관심 카테고리 맞춤 알림
- **혜택 신청 대행 알림 트래킹** — 신청 후 처리 상태 추적 연동 (지자체 API 확장 시)
