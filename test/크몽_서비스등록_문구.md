# 크몽 서비스 등록 문구 (웹 크롤링/스크래핑 외주)

## 서비스 제목 (택 1, A/B 테스트 추천)
- 원하는 웹사이트 데이터 자동 수집해드립니다 | 크롤링/스크래핑 외주
- [정확·빠름] 쇼핑몰·부동산·채용정보 자동 수집 크롤러 제작
- 반복 작업 그만! 웹사이트 데이터 자동 수집 프로그램 제작해드립니다

## 한 줄 소개
원하시는 웹사이트에서 필요한 데이터(가격, 상품, 매물, 채용공고, 리뷰 등)를 자동으로 수집해 엑셀/CSV로 정리해드립니다.

## 상세 설명
매일 수작업으로 웹사이트를 돌아다니며 데이터를 복사·붙여넣기 하고 계신가요?
그 시간을 자동화 프로그램 하나로 없애드립니다.

**이런 분들께 추천합니다**
- 경쟁사 가격/상품을 주기적으로 모니터링하고 싶은 쇼핑몰 운영자
- 부동산 매물 정보를 자동으로 수집하고 싶은 분
- 채용공고, 뉴스, 커뮤니티 게시글 등을 주기적으로 수집해야 하는 분
- 특정 사이트의 데이터를 엑셀로 정리해야 하는데 반복 작업이 지겨운 분

**작업 프로세스**
1. 원하시는 사이트 URL과 수집하고 싶은 데이터 항목 전달
2. 사이트 구조 분석 후 견적 및 소요기간 안내 (1일 이내 회신)
3. 크롤러 제작 및 샘플 데이터 전달 (검수 요청)
4. 최종 수정 및 결과물(코드 + 실행 방법 안내 또는 CSV/엑셀 파일) 전달

**포함 사항**
- 실행 가능한 Python 크롤링 코드
- 결과 데이터 (CSV/Excel 파일)
- 간단한 실행 가이드 (초보자도 따라할 수 있게)
- 1회 무료 수정

## FAQ
**Q. 로그인이 필요한 사이트도 가능한가요?**
A. 네, 가능합니다. 다만 사이트 이용약관에 따라 진행 가능 여부를 먼저 확인해드립니다.

**Q. 매일/매주 자동으로 실행되게 할 수 있나요?**
A. 네, 스케줄러 연동(Standard 이상)으로 자동 실행 및 결과 알림까지 세팅 가능합니다.

**Q. 코드를 모르는데 결과물을 어떻게 받나요?**
A. 실행 파일 형태 또는 결과 데이터(CSV/엑셀)만 정기적으로 전달받는 방식도 가능합니다.

**Q. 법적으로 문제없나요?**
A. robots.txt 및 이용약관을 준수하는 선에서 공개된 데이터만 수집합니다. 개인정보나 저작권 침해 소지가 있는 수집은 진행하지 않습니다.
